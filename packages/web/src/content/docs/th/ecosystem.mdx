ชุดโครงการชุมชนที่สร้างขึ้นบน Nebula

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Nebula ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-nebula](https://github.com/awesome-nebula/awesome-nebula) และ [nebula.cafe](https://nebula.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
